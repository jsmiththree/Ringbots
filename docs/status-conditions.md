# Status conditions

Source: the status-condition list, plus the stacking rule in the combat glossary.

A Ringbot can carry one instance of each status at a time. Applying a status the target already has clears the previous instance first, including when the new one is weaker, and then applies the new one.

| Status | Effect |
| --- | --- |
| Stop | No actions for the duration. A hit ends it immediately. |
| Flow | Armour on every part ticks down until the status ends or that part's Armour is 1. |
| Mask | Lowers Rate of Success until the status ends. |
| Chaos | The affected Ringbot cannot choose a target, and its attacks may hit allies. Strike and Berserk go to the nearest Ringbot that can be targeted. It cannot attack itself. |
| Ensnared | Evasion is 0 until the status ends. |
| Enfeebled | The defense stat is 0 until the status ends. Defense is not a base stat; see [stats.md](stats.md). |
| Impair | One arm is disabled and cannot be used until the status ends. |
| Braced | Incoming damage is reduced to 0 when it is below the remaining Armour of the part that would be hit. Lasts until the status ends. |
| Nullify | Clears every other status, and blocks new statuses, until Nullify ends. |
| Feedback | A portion of damage received is dealt back to the source. Grapple attacks only. Lasts until the status ends. |
| Chrome | Armour values cannot change until the status ends. |

How long each one lasts is set by the Technique or effect that applied it, not by the status itself.
